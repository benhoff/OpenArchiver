## Check Pushed Emails

`POST /api/v1/ingestion-sources/{id}/emails/check` checks Outlook COM message fingerprints and returns which messages are already archived.

## Bulk Import Pushed Emails

`POST /api/v1/ingestion-sources/{id}/emails/bulk` imports base64-encoded EML payloads generated by the Windows Outlook COM agent.
